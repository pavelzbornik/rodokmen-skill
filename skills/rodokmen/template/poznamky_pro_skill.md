# Poznámky pro správce skillu „rodokmen“

Sem Claude zapisuje chyby nástrojů, nové archivy, postupy a nápady. Rodinné údaje sem nepatří.

Chybu, která se projeví i v původním skillu, můžete nahlásit v [jeho GitHub Issues](https://github.com/sarsonj/rodokmen-skill/issues).
